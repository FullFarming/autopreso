# 디자인 정책 적용 및 검수 — 2026-09-05

## 적용 범위

승인된 시안을 기존 제품에 적용했다. 새 앱이나 배포를 만들지 않았고 기존 작업 트리의 다른 기능 변경을 보존했다. Product Design, frontend-ui-engineering과 Apple의 Buttons/Alerts HIG를 참고했다. iPhone 전용 Apple 디자인 스킬을 데스크톱 검증에 사용했다고 주장하지 않는다.

- 데스크톱 캡션: 단일 열 준비 폼, 작은 미리보기, 검색형 다중 언어 선택 및 자국어 표기, 용어집 관리의 설정 이동.
- 컨트롤러: 마이크·자막·출력·종료 버튼, 자막 위치/18–72px 크기/배경 투명도 실시간 조정, 화면별 출력 선택. 내장 화면 우선 배치와 기본 전체 화면 출력, 기존 선택 보존.
- 웹 참가자: 지구본과 더보기 중복 제거, 화면 언어와 자막 언어 분리, 16/24px 문단과 넓은 본문, 마이크 아이콘과 보이는 동작 문구.
- 용어집·QR·관리자 확인창: 제한된 창 크기, 본문 스크롤, 고정 하단 동작, 긴 제목/용어 줄바꿈, 일반 버튼 44px/8px, 초기 초점과 닫힌 뒤 초점 복원.
- 주요 데스크톱 버튼·포커스 색을 기존 토큰에서 Apple Blue로 정리. 관리자 저장과 계정 비활성화의 동작 유형을 구분.

## 검수 중 수정한 결함

1. 작은 데스크톱 용어집 상세에서 목록·입력폼이 겹치고 저장 버튼이 가려짐: 목록의 잘못된 축소를 제거하고 본문 스크롤로 통합.
2. 모달의 상속된 최소 너비와 `100vw` 계산이 여백을 깨뜨림: 최소 너비 해제 및 실제 사용 가능한 너비 기준으로 수정.
3. 컨트롤러의 화면 높이·외부 여백 계산 누락으로 설정창 하단이 잘림: 사용 가능한 화면 높이 전달과 창 측정 보정.
4. 배경 완전 투명 값이 다시 0.2로 복원됨: 입력·저장·표시 경계에서 0을 보존.
5. 연결 중단 중 외관 조정값이 전달되지 않음: 마지막 조정값을 연결 복구 시 재전송. 최종 값과 오래된 설정 응답의 경합 방지.
6. 두 번째 PDF 후보의 반복 ID가 첫 번째 후보를 덮어씀: 문서별 후보 ID 분리.
7. 붙여넣은 용어집을 수정한 후 이전 검증 결과로 등록 가능: 수정 시 검증 상태 무효화.
8. 참가자 발언 버튼이 원형 아이콘만 표시됨: 마이크와 실제 상태의 현지화 문구 표시.

내부 스크롤로 용어집 입력폼에 도달했을 때 저장 버튼 아래쪽 443px, 고정 하단 영역 시작 491px로 겹침이 제거됨을 확인했다. English 화면 언어로 변경 후에도 한국어 자막 탭이 유지됐다. 한국어 검색어 `일본어`로 `日本語`가 조회됐다.

Next 개발 도구가 문서에 추가한 49px 바깥 스크롤은 제품 본문 자체의 넘침과 구별했다. 제품 본문은 568px 안에 들어갔으며 이를 숨기기 위한 전역 CSS를 추가하지 않았다.
