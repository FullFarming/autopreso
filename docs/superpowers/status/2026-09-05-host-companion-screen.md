# 웹 호스트 QR·진행 화면

## 확정 범위

데스크톱이 음성을 송출하고, 같은 계정으로 로그인한 태블릿·노트북 웹앱은 기존 회의의 QR과 진행 내용을 표시한다. 웹 기기로 마이크 송출을 넘겨받지 않는다. 이 화면을 닫아도 회의를 종료하지 않는다.

## 사용 방법

1. 데스크톱에서 호스트 계정으로 Live Call을 준비하고 참여자 입장을 연다.
2. 태블릿 또는 노트북에서 같은 서비스의 웹 주소를 열고 동일한 호스트 계정으로 로그인한다.
3. 호스트 대시보드의 **QR·진행 화면**을 누른다. 직접 경로는 `/host-screen`이다.
4. 준비 중·진행 중·일시 정지된 내 회의 중 하나를 선택한다.
5. 참여자가 화면의 QR을 스캔한다. 기존 참여 코드가 링크에 포함되어 입력 화면에 자동 반영된다.

준비 중에는 일정 카운트다운, QR, 참여 코드와 참여 인원을 표시한다. 진행 중에는 QR과 자막 미리보기를 표시한다. 종료되면 QR과 진행 내용을 제거하고 종료 화면을 표시한다. 일정 도달만으로 회의가 시작되지는 않는다.

## 연결 및 권한

- 기존 내 세션 목록 API를 사용하며 페이지를 모두 읽고 종료된 세션을 제외한다.
- `/stage/[id]`에서 기존 세션과 참여 활동을 읽는다. 기본 갱신 간격은 요청 완료 후 5초이다. 같은 브라우저의 상태 알림은 빠른 갱신에 사용한다.
- 기존 초대를 `read-if-open`으로 읽는다. 이 화면에서 초대를 새로 만들거나 유효기간을 연장하거나 회의를 시작하지 않는다.
- QR 주소는 서버에서 확인한 참여 코드로 생성한다. 주소 해시로 전달된 코드를 호스트 화면의 근거로 신뢰하지 않는다.
- 접근 거부·인증 만료·삭제 응답이 오면 세션, QR, 참여자, 자막을 지운다. 늦게 도착한 이전 요청이 내용을 다시 표시하지 못하도록 요청 세대를 확인한다.
- 음성 캡처, 게이트웨이 연결, 번역 엔진 시작은 추가하지 않았다. 새로운 DB 필드나 환경 변수도 없다.

## 운영자가 확인할 사항

- 다른 기기에서 사용하려면 이번 변경을 실제 공용 HTTPS 웹 서비스에 배포해야 한다. 이번 작업에서는 배포하지 않았다.
- 데스크톱과 웹앱은 같은 인증·세션 저장소를 사용해야 한다. 다른 프로젝트의 계정이나 DB에는 준비한 회의가 표시되지 않는다.
- `127.0.0.1` 또는 `localhost` 주소는 태블릿에서 데스크톱을 가리키지 않는다. QR 화면은 참여자가 접근할 수 있는 공용 웹 도메인에서 열어야 한다.
- 기존 Google 로그인 설정과 허용 리디렉션 주소가 실제 웹 도메인에 맞아야 한다. 로그인 후 대시보드에서 QR·진행 화면 메뉴를 이용한다.
- 참여자 입장이 닫혀 있거나 코드가 만료되었다면 데스크톱에서 입장을 열어야 한다. 이 화면은 입장 정책을 변경하지 않는다.

## 검증

- 웹 자동 테스트: 993개 Live 테스트 + 77개 Core 테스트 통과.
- 웹 TypeScript 검사 통과.
- 데스크톱·공통 자동 테스트: 1,489개 통과, 16개 건너뜀, 실패 없음. 전체 변경의 공백 오류 검사 통과.
- 새 목록 로더 테스트 7개: 페이지 처리, 활성 세션 필터, 중복 제거, 실패·취소 등.
- Stage 접근 테스트 12개: 접근 거부, 종료, 지연 응답, 해시 코드 불신 및 읽기 전용 경로 등.
- 브라우저: 실제 React 화면에 로컬 모의 응답을 공급하여 목록·준비·진행·종료·인증 만료를 확인했다. 임시 모의 응답 파일은 검증 후 제거하고 기존 기록 데모를 복구했다.
- 1024×768 및 390×844 화면에서 확인했다. 긴 제목에서 프레임 내용이 잘리는 문제를 수정했고 QR 크기를 확대했다. 긴 내용은 페이지를 스크롤하여 볼 수 있다.
- 미인증 `/host-screen` 접근이 로그인 화면으로 이동하는 것을 확인했다.

### 적대적 검증

| 항목 | 결과 | 근거 및 한계 |
| --- | --- | --- |
| 동시성·지연 응답 | 통과 | 이전 요청과 해제된 화면의 응답이 상태를 되살리지 않는 자동 테스트 |
| 권한 실패 | 통과 | 401·403·404 이후 private 상태 제거 테스트와 브라우저 401 시연 |
| 종료 상태 잔류 | 통과 | 종료 시 QR·자막 제거 자동 테스트 및 브라우저 시연 |
| 입력 경계 | 통과 | 목록 응답 스키마, 중복, 페이지 진행 및 취소 검사 |
| 태블릿·모바일 배치 | 통과 | 지정 화면 크기에서 QR·긴 제목·내용 영역 확인 |
| CSRF·XSS·SSRF 신규 경로 | 신규 없음 | 기존 인증 API 재사용, React 텍스트 출력. 이 변경에서 외부 URL 가져오기나 HTML 삽입 없음 |

실제 Supabase 로그인, 물리적 태블릿·휴대폰 간 QR 스캔, 실제 오디오와 동시 송출은 이번 로컬 환경에서 검증하지 않았다. 모의 브라우저 검증을 실제 운영 연동 완료로 간주하면 안 된다.
