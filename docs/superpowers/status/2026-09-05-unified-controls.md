# 버튼 통일 및 캡션 실행 화면 개선

상태: 로컬 구현·검증 완료. 운영 배포 미실행. 2026-09-05 사용자 화면 주석 요청 기준.

## 근거와 설계

첨부 화면의 ‘현장 발언자로 선택’이 여러 줄로 늘어나 이웃 수정 버튼과 높이가 달랐다. 캡션 화면은 시작 전에 용어집·글꼴·여백까지 펼쳐져 있어 실행에 필요한 조작을 찾기 어려웠다.

- 일반 버튼·선택 입력·텍스트 입력 기본 높이 44px, 단일 행의 짧은 행동 이름.
- 긴 설명은 오른쪽 독립 도움말 버튼으로 분리한다. 중요한 오류와 종료 영향은 숨기지 않는다.
- 도움말은 클릭·키보드·터치로 열고 Escape로 닫는다. 폼 제출이나 이웃 버튼 실행과 분리한다.
- 캡션 기본 화면은 언어·출력 화면·시작 중심. 용어집·모양·위치 설정은 접어서 보존한다.
- 콘텐츠 목록, 여러 줄 텍스트 입력, 슬라이더 및 체크박스 내부 모양은 용도에 맞는 예외다.

`DESIGN.md` 최상단에 동일 정책을 반영했다. desktop public 자산과 webapp 컴포넌트로 소유 범위를 나누고 인증·음성 파이프라인은 변경하지 않는다.

## 검증 계획

1. 1024×768 / 375×568에서 버튼 높이·가로 넘침·도움말 화면 경계 확인.
2. 도움말 클릭 시 세션 시작·저장·제출이 실행되지 않는지, Escape와 포커스 복귀 확인.
3. 상세 설정 열기·닫기 이후 언어/모양 값과 실행 상태 유지 확인.
4. 짧은 라벨에도 접근성 이름으로 행동 대상을 구분할 수 있는지 확인.
5. 관련 루트·웹 테스트와 타입 검사, 변경 diff 검토.

DB 마이그레이션이나 새 계정·환경 변수 설정은 이번 UI 변경에 필요하지 않다. 운영 배포는 별도다.

## 웹 실측 결과

실제 `/records/demo` 컴포넌트를 1024×768에서 검사한 결과 뒤로가기·Excel 저장·도움말·기록 탭·이전/다음·삭제 10개 버튼이 모두 높이 44px였다. 페이지 가로 넘침은 없었다.

375×568에서도 Excel 저장과 도움말은 44px였다. 도움말은 x16, 너비328px로 화면 내부에 표시되었고 Escape 후 도움말 버튼에 포커스가 복귀했다. 긴 영문 기록 탭 겹침을 발견해 탭 너비와 간격을 보존하는 가로 스크롤로 수정했다. 새 버튼과 설명도 시스템 언어를 따른다.

증거: `output/2026-09-05-unified-controls/web-help-mobile.jpg`, `web-help-desktop.jpg`.

웹 전체 테스트: Live 1,024 + Core 77 = 1,101 통과, 실패 0. 웹 타입 검사 통과. 기존 긴 문구를 그대로 요구하던 검사 두 곳은 새 라벨과 실제 실행 핸들러·중복 실행 방지 검증으로 갱신했다.

## 캡션·컨트롤러 결과

- 기본 캡션은 언어·표시 화면·접힌 세부 설정·현재 자막으로 정리했다. 용어집, 글꼴, 위치, 크기, 배경 투명도는 세부 설정에 보존한다.
- 화면 선택은 기존 Electron 화면 선택 기능에 연결한다. 일반 자막 설정 저장과 이벤트를 분리했다.
- 1024×768에서 캡션과 컨트롤러의 보이는 일반 버튼 높이44px, 페이지 가로 넘침 없음. 375×568 도움말280px너비 x79..359로 화면 내부 유지.
- 두 화면 선택, 모두 해제해 ‘표시 안 함’, 내장 화면 재선택을 모의 IPC에서 시연했다. Space 선택 후 포커스 유지 및 Tab으로 새로고침 이동 확인.
- 상세 설정을 닫았다 열어도 글자 크기48 값 유지. 도움말 Escape 후 부모 오디오 설정창 유지와 도움말 버튼 포커스 복귀 확인.
- 루트 전체 테스트: 1,505 통과, 19 건너뜀, 실패0. 웹1,101과 합계2,606 통과. 루트·웹 타입 검사, git diff 공백 검사 통과.

### 검수에서 고친 결함

1. 도움말 문구 갱신이 관찰자를 반복 호출하는 문제: 같은 값 재할당 방지.
2. 명단 재렌더링 후 고아 도움말과 중복 ID: 연결 해제 요소 정리 및 단조 증가 ID.
3. Escape가 부모 설정창까지 닫는 문제: 이벤트 전파 차단.
4. 오래된 화면 목록이 최신 선택을 덮는 문제: 변경 세대 검사.
5. 화면 체크박스 재렌더링 시 포커스 소실: 기존 DOM 유지.
6. 화면 선택이 일반 설정 저장까지 호출하는 문제: input/change 전파 분리.
7. 밝은 테마 도움말 대비 및 창 크기 변경 후 위치 보정.

추가 read-only 검수에서 미해결 P1/P2는 발견하지 못했다. 권한·DB·외부 URL 처리는 이번 UI 변경 대상이 아니며, 새 외부 호출이나 스키마는 추가하지 않았다.

화면 증거: `output/2026-09-05-unified-controls/caption-after.jpg`, `caption-mobile.jpg`, `controller-after.jpg`.

검토 주소: http://127.0.0.1:3322/subtitle.html . 실제 public 렌더러에 모의 IPC를 연결한 로컬 시연이다. 실제 송출·클라우드 로그인·물리 디스플레이 적용은 이 시연으로 검증하지 않는다. 시연의 연결 상태는 실제 모델 연결을 의미하지 않는다. 검토 서버는 주석을 이어갈 수 있도록 유지했다. 기존 Canvas 프로젝트는 변경하지 않았다.

이번 UI 수정만 적용하려면 웹앱 및 Electron의 기존 빌드/갱신 절차를 따른다. 새로운 DB 작업이나 환경 변수는 없다. 문제가 생기면 이 UI 변경 파일을 이전 버전으로 되돌리며 저장된 설정과 회의 데이터는 유지한다.
