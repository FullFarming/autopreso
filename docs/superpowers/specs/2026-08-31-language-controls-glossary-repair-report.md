# 언어 버튼·한국어 혼합 발화·용어집 시작 오류 수정

2026-08-31. 사용자의 기존 전체 재빌드·배포 승인을 이어 적용한다. 기존 작업 트리·고객 기록·로그인 설정은 보존한다. 이 문서는 이번 변경과 최종 배포 증거를 기록한다.

## 사용자 동작

- 참여자 언어 선택을 44px 버튼으로 표시한다. 한국어·English·日本語 등 언어 이름은 각 언어의 자국어 표기를 사용하며, 원문 버튼만 시스템 언어에 따라 번역한다. 호스트가 제공하는 언어 목록과 실제 선택 코드는 바꾸지 않는다.
- 발언권 버튼은 기존 중앙 캡슐 너비를 유지하고 녹음 원형 → 연결 중 → 정지 사각형 아이콘으로 전환한다. 보이는 버튼 문구는 제거하고 스크린리더 이름·키보드 초점·비활성화·동작 줄이기 설정은 유지한다. 발언 기능이 없는 회의의 빈 공간 정책도 보존한다. 실제 재생 기능이 없어 재생 버튼을 추가하지 않는다.
- 원문은 실제 발화를 보존한다. 한국어 번역에서 일반 영단어를 대문자라는 이유로 고유명사로 인정하지 않는다. 고정된 용어집이 명시한 보존 표기와 해당 목표 언어의 등록 표기만 보호한다. 이 검사는 잘못된 문자 혼합을 거르는 장치이며 번역의 의미 정확성을 증명하지 않는다.

## 모델 선택

공식 모델명은 Gemini 3.7 Flash이며, “3.7d Flash”라는 모델을 설정하지 않는다. 원문은 3.5 Transcribe Live, 확정 번역·요약은 기존 3.7 Flash 경로를 유지한다.

3.5 Live Translate는 음성 입력을 받아 음성 및 전사를 출력하는 별도 서비스다. 3.7의 원문 텍스트를 번역 입력으로 넣거나 시스템 지시·용어집을 같은 방식으로 전달할 수 없다. 기존 소규모 시험에서도 원문과 번역의 문장별 완료 경계를 검증하지 못했다. 따라서 두 음성 경로를 중복 실행하거나 연속 출력에 임의로 원문 ID를 붙이지 않는다. 이번 변경을 모든 번역 언어의 연속 부분 자막까지 완성한 것으로 보고하지 않는다.

근거: [Live Transcribe](https://ai.google.dev/gemini-api/docs/live-api/live-transcribe), [Live Translate](https://ai.google.dev/gemini-api/docs/live-api/live-translate), [Gemini 3.7 Flash](https://ai.google.dev/gemini-api/docs/models/gemini-3.7-flash). 기존 판단과 시험 한계는 [고정 언어 구현 보고](2026-08-31-fixed-target-language-implementation.md)에 있다.

## 후속 수정: 예약 전 호스트 수동 시작

서버·SQL에는 미래 예약 시각을 이유로 수동 시작을 거절하는 조건이 없었다. 운영 함수 정의를 읽기 전용으로 확인했고, 격리 SQL에서 1시간 뒤 예약된 회의가 정상 준비 확인을 거쳐 `live`로 전환됐다. 새 DB migration이나 예약값 변경은 필요하지 않았다.

확정된 화면 결함은 일반 수동 클릭이 즉시 연결 함수를 실행하지 않고 예약 clock effect에 위임한다는 점이었다. 특히 예약값이 없는 세션은 effect의 일정 검사에서 멈췄고, 연결 처리 중에도 미래 예약 카운트다운이 표시됐다. 수동 클릭을 기존 권한·용어집·마이크·준비 확인 경로의 `startBroadcast(true)`에 직접 연결했다. 현재 고객이 겪은 모든 연결 실패가 예약 시간 때문이라고 단정하지 않는다. 최근 운영 로그에 명시적 실패 코드가 없었지만 일부 오류는 WebSocket으로만 전달되어 로그만으로 성공을 입증할 수 없다.

- 연속 클릭과 예약 타이머가 겹쳐도 진행 중인 시작 요청은 하나만 유지한다.
- 수동 실패·예외 후에는 자동 예약 재시도를 중단하며, 사용자가 직접 다시 시도할 수 있다.
- 숨겨진 페이지의 늦은 완료에서도 해당 실행의 잠금과 성공/실패 상태를 정리한다. 새 세션/세대의 상태를 덮어쓰지 않으며, 오래된 자동 효과가 새 유료 시작을 호출하지 못한다.
- 대기·워밍 상태에만 예약 카운트다운을 보여준다. 연결·확인 중에는 예정 시각까지 기다리는 것으로 표시하지 않는다.
- 예약 시간과 정상 자동 시작 조건, 실제 `live` 상태를 기준으로 하는 참여자/스테이지 전환, 기존 로그인·소유권·용어집·버전 검사는 그대로 유지한다.
