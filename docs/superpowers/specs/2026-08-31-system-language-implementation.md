# 시스템 언어 선택 구현·검증 기록

작성일: 2026-08-31

## 요구사항과 결정

웹앱과 Electron의 우측 상단에 지구본과 현재 언어를 표시하는 공통 버튼을 추가했다. 선택지는 한국어(기본), English, 日本語다. 설정·입장·로그인·호스트·참여자·기록·용어집·요약 화면의 시스템 문구를 변경한다. 발표용 `/stage`와 자막 투사 화면에는 조작 버튼을 추가하지 않는다.

시스템 언어는 자막 대상 언어와 독립적이다. 원문, 번역 결과, AI 요약, 사용자 제목·이름·용어는 변경하지 않는다. 언어 변경은 사전 조회와 화면 갱신만 수행하며 AI 호출, 통화 재시작, 요약 재생성, 인증 갱신을 발생시키지 않는다.

- 공통 계약: `public/system-language.js`의 세 언어 코드·기본값·표시명·저장 키.
- 웹: `webapp/components/system-language/`의 Provider·Button·Shell, `webapp/lib/system-language/`의 기능별 사전. 안정된 번역 함수 참조로 연결 effect 재실행을 방지한다.
- 웹 저장: 언어 값만 localStorage와 1년짜리 SameSite=Lax 설정 쿠키에 보관한다. HTTPS에서는 Secure를 사용한다. 인증 쿠키와 별개이며 SSR 초기 언어도 일치시킨다.
- Electron: `public/system-language-button.js`를 메인 창·제어창에서 재사용한다. `electron/system-language-store.js`는 userData 안의 별도 `system-language.json`에 원자적으로 저장하므로 로컬 서버 포트가 바뀌어도 유지된다.
- Electron IPC 읽기·쓰기는 기존 로컬 앱 origin만 허용한다. 실제 자막 설정 파일은 변경하지 않는다.
- 웹과 앱 사이의 계정 기반 자동 동기화는 추가하지 않았다. 각 브라우저/앱에서 설정을 유지한다.

## 검토에서 발견하고 수정한 문제

1. 시스템 언어 변경이 저장하지 않은 번역 대상·프리셋을 덮고 기록을 다시 조회하던 기존 데스크톱 동작을 제거했다.
2. 한국어 aria-label을 CSS 선택자로 사용해 영어·일본어에서 자막 배치가 깨지던 부분을 언어와 무관한 선택자로 바꿨다.
3. 늦은 Electron 복원 응답과 다른 탭의 과거 저장 이벤트가 최신 선택을 덮어쓰지 않게 했다.
4. 데스크톱 저장 실패를 화면에 표시하고 동일 언어 재선택으로만 수동 저장을 다시 시도한다. 자동 재시도는 없다.
5. 언어 전환 때 자막 위치 설정 행이 숨겨지지 않도록 현재 선택과 동기화한다.

| Electron main/preload 문법 검사·diff 검사 | PASS |

실제 브라우저에서 입장·로그인·기록·라이브 화면과 Electron이 사용하는 메인/제어창 화면을 확인했다. KO 자막 선택 상태에서 시스템 EN→JA 전환 시 자막 내용과 선택이 유지된다. 새로고침 후에도 시스템 언어가 유지되고, 메인/제어창 간 변경이 반영된다. 라이브 화면 높이 720px에서 하단 마이크 버튼의 아래쪽 위치는 680px로 화면 안에 유지된다. 제어창 메뉴는 222px 높이 안에 표시된다.

실제 React 검증에서 Provider 120회, 기록 126회, 회의록 124회 언어 전환 동안 자식/연결·조회 타이머가 다시 생성되지 않았고 추가 요청은 0회였다. SSR와 저장 언어가 다른 네 가지 상황에서 hydration 오류는 0건이었다. 새 프로세스로 테스트용 저장 파일을 다시 읽어 일본어 복원도 확인했다.

## 적대적 검증

| 항목 | 결과와 범위 |
| --- | --- |
| A1 동시성 | PASS — 늦은 복원·과거 storage 이벤트·이전 저장 실패 응답이 최신 선택을 덮지 않음 |
| A2 권한 | PASS — 외부 origin, 유사 도메인, 다른 포트, URL credentials, file 스킴의 언어 IPC 거부 |
| A3 CSRF | 새 HTTP 변경 endpoint 없음. 기존 인증·CSRF 정책 불변, IPC는 strict origin 검증 |
| A4 XSS | PASS — 문구와 치환 값은 React/DOM 텍스트로 출력, HTML 삽입 없음 |
| A5 SSRF | N/A — 사용자 URL 조회 기능이나 새 외부 IO 없음 |
| A6 입력 경계 | PASS — 미지원 언어·객체·배열·잘못된 저장 JSON·저장 차단 검증 |
| A7 상태 잔류 | PASS — 자막 선택·원문·입력 중 설정 유지, 타이머/조회 재시작 없음 |
| A8 화면·입력 | 화면 및 키보드·Escape·포커스·메뉴 높이 검증. 실제 iPhone/iPad 및 설치된 Electron 바이너리의 기기별 시연은 미실시 |

처음 병렬 전체 실행 중 기존 용어 검색의 30ms 성능 기준이 1회 초과됐다. 해당 로직이나 기준은 변경하지 않았고 최종 전체 실행에서는 통과했다. 최종 기능 결함은 확인되지 않았지만, 이 성능 검사는 호스트 부하의 영향을 받는다. 커버리지 비율은 별도 산출하지 않았다.

## 배포와 롤백

로컬 구현 및 검증까지 완료했다. 운영 배포, DB 변경, 이메일 발송, 유료 AI 호출은 하지 않았다. 기존 사용자 개발 서버를 건드리지 않도록 production 빌드는 `/tmp/nova-system-language-build-20260831/autopreso`에서 실행했다. Electron 설치 파일 재패키징 및 실제 설치 검증은 이번 결과에 포함하지 않는다.

롤백은 해당 시스템 언어 UI/사전/저장 연결 변경만 되돌린다. 언어 설정 파일과 쿠키는 인증·자막 데이터와 분리되어 있어 DB 마이그레이션이나 기록 삭제가 필요 없다. 이전 라이브 번역 변경 및 사용자의 다른 작업은 유지한다.
