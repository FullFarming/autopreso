## 참여자 모바일·예약 QR 추가 요구

- 웹 호스트 화면과 참여자 모바일 화면을 분리한다.
- 모바일 흐름: QR 스캔 → 이름·기존 필수 정보와 동의 → 예약 대기 → 호스트 시작 시 실시간 자막.
- QR 초대 경로에는 인증코드 입력이 없다. QR 자체의 유효한 초대 자격을 서버에서 확인하며, 일반 직접 진입의 코드 경로와 구분한다.
- 예약 시 발급·공유한 QR은 일정까지 같은 값을 유지하고 진행 중에도 사용 가능하게 한다. 일정 변경 시 같은 QR이 변경된 일정을 가리킨다.
- 예정 시각이 지나도 호스트가 시작하지 않았다면 대기 상태를 유지한다. 회의 종료는 호스트가 결정한다.
- 재공유·새로고침·일반 복구로 QR을 재발급하거나 기존 QR을 폐기하지 않는다. 호스트가 명시적으로 초대 링크 재발급·폐기, 회의 취소·종료한 경우는 별도 처리한다.
- 장기 초대 링크 수명과 짧은 접속 토큰/실시간 연결 수명을 분리한다. 초대 링크가 서버에서 무제한 권한을 주는 형태로 구현하지 않는다.
- 기존 코드에는 invite 기반 코드 없는 입장이 있다. 초대 재생성 시 토큰 교체, 일정 변경 시 초대 만료 동기화, 입장창과 초대 수명의 UI 결합을 추가 수정해야 한다.

## 화면 언어·자막 언어·참여자 공유 확정 요구

사용자는 어닝콜 방식 수정 시안을 수용하고 다음을 추가 요청했다. 아래는 구현 계약이며 기능 완료 보고가 아니다.

- 자막 선택의 언어명은 해당 언어의 자국어 표기: `한국어`, `English`, `日本語`. 예시 세 언어로 고정하지 않고 호스트가 설정한 최대 3개 출력 언어 중 참여자가 보고 싶은 언어를 선택한다.
- 오른쪽 상단 점 세 개 왼쪽에 지구본 버튼을 배치한다. 지구본은 시스템 화면 언어 선택, 자막 영역의 언어 선택은 자막 표시용으로 구분한다.
- 시스템 언어는 메뉴·버튼·입장·대기·상태·오류·공유 안내 등 UI 문구에 적용한다. 회의 제목이나 발언 원문을 임의로 번역·변경하지 않는다. 자막 언어, 원문 표시, 참여자 정보, 연결 상태는 유지한다.
