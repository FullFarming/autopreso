# Realtime Noel One-Slide Brief

## Slide Goal

발표자와 청중이 언어 장벽 없이 같은 흐름을 따라가도록, 시스템 오디오와 마이크 음성을 실시간으로 번역해 화면 위 자막 레이어로 보여주는 데스크톱 앱 기획을 한 장으로 전달한다.

## Slide Copy

### Title

Realtime Noel: 실시간 발표 번역 자막 레이어

### Subtitle

마이크와 시스템 오디오를 동시에 듣고, 영어와 한국어를 양방향으로 번역해 발표 화면 위에 바로 띄웁니다.

## Visual Hierarchy

1. 상단 35%: 제품명과 한 줄 설명
2. 중단 35%: `Problem → Solution → Value` 3단 구조
3. 하단 20%: 오디오 처리 흐름 다이어그램
4. 하단 보조 10%: 신뢰성, 제어, 기록 기능을 작은 카드 3개로 정리

## Key Message

Realtime Noel은 단순 번역기가 아니라, 발표 현장에서 끊기지 않는 이해 흐름을 만들기 위한 실시간 자막 인프라다.

## Feature Points

- 마이크와 시스템 오디오 동시 캡처
- 영어와 한국어 양방향 실시간 번역
- 발표 화면 위에 항상 보이는 자막 오버레이
- 오버레이 켜기/끄기, 자막 위치/크기 조절
- 날짜별 번역 기록과 주제별 기록 분류
- OpenAI API 키 사전 검증
- 무음 입력, 연결 끊김, 권한 실패를 사용자에게 표시

## Speaker Note

기존 번역 앱은 텍스트 입력이나 회의록 중심입니다. Realtime Noel은 발표 중 실제로 문제가 되는 지점, 즉 말소리 입력, 언어 전환, 자막 표시, 기록 정리를 하나의 흐름으로 묶습니다. 발표자는 슬라이드나 데모에 집중하고, 청중은 실시간 번역 자막으로 내용을 따라갈 수 있습니다.

## Design Direction

- 배경: 밝은 회색 또는 흰색
- 핵심 강조: 제품명과 `Mic / System audio → Realtime translation → Overlay`
- 시각 요소: 마이크, 시스템 오디오, 번역 엔진, 오버레이 화면을 4단 흐름으로 표현
- 문장 길이: 각 카드당 2줄 이내
- 피해야 할 것: 긴 기능 목록, 기술 스택 나열, 복잡한 아키텍처 다이어그램

## Final One-Line Takeaway

말하는 순간 번역되고, 발표 화면 위에 바로 보이며, 기록까지 남는 실시간 자막 도구.
